# Segurança

Achou um jeito de descobrir quem tirou quem, entrar como organizador, mandar e-mail pela conta do site ou qualquer outra falha?

**Não abra issue pública.** Reporte em particular: aba **Security → Report a vulnerability** deste repositório.

Ajuda muito mandar:
- o passo a passo para reproduzir;
- o que dá para ver ou fazer com a falha;
- se possível, uma sugestão de correção.

Teste só no ambiente local (`npm run dev`). Não faça teste de carga, chute de senha nem sorteio no site em produção: ele manda e-mail de verdade.
